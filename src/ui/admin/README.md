# ui/admin

Super Admin 和机构管理端共用的桌面组件：应用框架（侧边导航、租户名、Demo / 支持访问标识条）、页面头部、带筛选和排序的数据表、输入名称确认的危险操作对话框、数字卡片。规格见 meta repo `06-app-development/design/COMPONENTS.md` §12A。

## 后台视觉统一（18/10/2026）

Owner: Lightman · Status: Local revision · Last reviewed: 18/10/2026

AppShell 导航支持可选线性图标与手机导航后收起；DataTable 的手机字段标识与基础 Table 一致。
