# brand

careKind 标准 Logo（04A 星芒字标）的黑、白两版 SVG 副本。母版和使用规范在 meta repo 的 `06-app-development/design/logo/`（ADR-0003）。

## 怎么用
```tsx
import logoBlackUrl from "@carekind/shared/brand/carekind-logo-black.svg";
<img src={logoBlackUrl} alt="careKind" width={160} />
```
最小宽度 160px；白底用黑版，深色底用白版；不要裁切或改色。
